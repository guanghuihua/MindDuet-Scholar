# CTRW

This is the code related to my graduation thesis.

## Map

- `Canard/`, `Canard_EM/`, `comparsion/`: core canard and comparison
  experiments.
- `26.01/`, `26.02/`, `26.03/`: dated experiment runs, figures and analysis
  scripts.
- `师姐程序/`: reference programs from earlier work.
- `论文V0/` through `论文V4/`: thesis drafts, figures and presentation
  material.

Keep source code, notebooks, TeX sources, final PDFs and meaningful figures in
Git. Local Python caches, LaTeX intermediate files and compiled binaries are
ignored because they can be regenerated.
