# 本地资产管理

## 原则

1. 教材和英语资料继续放在 MindDuet Scholar 项目内，供搜索、PDF Reader 和学习助手使用。
2. 大型二进制资产不进入 Git，也不上传 GitHub。
3. Markdown、LaTeX 源码、程序和小型 CSV 台账可以正常版本管理。
4. 不用文件名判断重复。只有逐字节一致的文件才可以删除重复副本。
5. 同名但内容不同的教材保存在对应学科的 `同书异版/`，等待人工比较 OCR、清晰度、版次和批注。

## Git 边界

`.gitignore` 排除整个 `英语学习/`，并排除 `数学教材/` 下的 PDF、电子书、Office 文档和压缩包。Git 忽略不会删除本地文件，MindDuet 的本地索引仍然可以读取它们。

检查某个文件为何被忽略：

```bash
git check-ignore -v -- "数学教材/路径/教材.pdf"
git check-ignore -v -- "英语学习/路径/音频.mp3"
```

更新台账：

```bash
.venv/bin/python tools/build_asset_inventory.py
```

详细记录生成到：

```text
docs/inventory/math-assets.csv
docs/inventory/english-assets.csv
```

## 备份边界

被 Git 忽略意味着 GitHub 不是这些资产的备份。重要教材、私人扫描件、批注版资料和英语训练音频仍应另外备份到移动硬盘、NAS 或私有云盘。
