# MindDuet Scholar 项目结构

这个项目把学习应用、个人笔记、本地教材和研究资料放在同一个工作目录中。它们不做物理上的 code/data 分离，但通过清晰的目录职责和 Git 规则区分“需要版本管理的知识成果”和“只留本机的大型资产”。

## 顶层目录

| 路径 | 职责 | Git 策略 |
| --- | --- | --- |
| `mindduet_scholar/` | FastAPI 应用、页面、索引器和学习助手 | 跟踪 |
| `tests/` | 自动化测试 | 跟踪 |
| `ATVault/` | 数学概念笔记、习题和证明记录 | 跟踪 |
| `数学教材/` | 本地数学教材，以及与教材配套的少量源码笔记 | 教材二进制忽略，文本与源码可跟踪 |
| `英语学习/` | IELTS、听力音频、阅读和写作资料 | 整个目录只留本地 |
| `数学实验/` | 可运行的数学探索，包括单纯同调和反演几何 | 源码、Notebook 与有意义的结果图跟踪 |
| `研究论文/` | CTRW 毕业论文与 Hamilton 系统研究材料 | 源码与论文材料跟踪，生成物忽略 |
| `计算机网络/` | WSL 与网络配置笔记 | 跟踪 |
| `docs/` | 项目结构、资产制度和小型台账 | 跟踪 |
| `.mindduet/` | SQLite、索引、PDF 上下文和临时 Codex 工作区 | 只留本地 |

## 日常放置规则

新的数学教材直接放进 `数学教材/` 中最接近的学科目录。存在同名文件但不能确认版本优劣时，放入该学科的 `同书异版/`，不要覆盖。

新的 IELTS 音频、PDF、电子书和训练材料放进 `英语学习/`。个人总结、错题分析和可长期积累的学习笔记应写进 Session、`ATVault/` 或单独的 Markdown，而不是只写在大型资产目录里。

可复现的数学代码、Notebook 和结果图放进 `数学实验/` 下对应主题目录。论文正文、论文专用程序和研究过程记录放进 `研究论文/` 下对应项目；不要把论文项目内部的相对路径随意拆开。

增加、删除或移动资料后，依次运行：

```bash
.venv/bin/python tools/build_asset_inventory.py
.venv/bin/mindduet index
```
